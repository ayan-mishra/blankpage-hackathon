# Somnium backend plan

Goal: email/password accounts and private cloud checklists, with recordings processed locally.

Architecture: keep vanilla JavaScript and the existing recording engine. Use the official
Supabase browser SDK with persisted sessions; Postgres RLS authorizes every checklist request.
Vite bundles the SDK and both existing HTML entry points. Only publishable configuration
is included in browser builds. No service-role key or recording upload is needed.

Assumptions: email/password signup with confirmation, login, logout, and password recovery;
users explicitly save named checklist snapshots, load them, and delete them. The demo stays
available without login. No OAuth, public sharing, profile table, or recording storage.
Account UI follows the existing system font, teal accent, dark/light palette and card layout.
